# AGENTS.md

This repository contains portable skills for AI agents.

- Each skill lives in `skills/<name>/`.
- Each skill has a required `SKILL.md`.
- Detailed templates live in `references/`.
- Completed examples live in `examples/`.
- Use `skills/cover-design-en/SKILL.md` for English cover-design work.
- Use `skills/cover-design-ru/SKILL.md` for Russian cover-design work.
