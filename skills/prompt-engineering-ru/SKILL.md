# Создание промптов

Используй навык, когда пользователь хочет сформулировать задачу для модели, улучшить промпт, разделить сложный запрос на этапы или сделать инструкцию пригодной для агента.

## Порядок работы

1. Определи цель, входные данные, ожидаемый результат и ограничения.
2. Убери двусмысленности: роли, формат ответа, критерии готовности, запреты и допущения.
3. Если задача сложная, раздели промпт на контекст, задачу, процесс и формат результата.
4. Добавь проверки качества: что модель должна проверить перед финальным ответом.
5. Сделай промпт достаточно коротким, чтобы его реально использовали.
6. Если полезно, предложи две версии: компактную и расширенную.

## Ограничения

- Не перегружай промпт очевидными инструкциями.
- Не добавляй противоречивые требования.
- Не обещай точность там, где нужны источники или внешняя проверка.
- В русскоязычных промптах и пояснениях используй букву `ё` с точками там, где она нужна; не заменяй её на `е`.
- Не злоупотребляй списками: максимум три пункта перечисления по умолчанию. Если примеров больше, оставь один-два через "или" либо сгруппируй их в короткую фразу; больше трёх пунктов используй только когда полный список действительно нужен.
